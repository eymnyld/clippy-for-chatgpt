# Import prompts

Use these after installing the `clippy-for-chatgpt` plugin and starting a new Codex task.

## English

```text
Use $install-clippy-pet to install the bundled Clippy pet into Codex and verify it. If a different Clippy pet would be overwritten, ask me first.
```

## Türkçe

```text
$install-clippy-pet becerisini kullanarak paketteki Clippy petini Codex'e kur ve doğrula. Farklı bir Clippy paketinin üzerine yazılacaksa önce benden onay iste.
```

## Verify only

```text
Use $install-clippy-pet to verify the installed Clippy pet without replacing or changing files.
```

## Uninstall

```text
Use $install-clippy-pet to uninstall only the bundled Clippy pet. Do not remove any other pet or Codex setting.
```
