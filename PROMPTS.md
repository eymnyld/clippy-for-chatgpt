# Import prompts

For a command-line-free installation, paste the complete standalone prompt from [INSTALL-PROMPT-EN.txt](INSTALL-PROMPT-EN.txt) or [INSTALL-PROMPT-TR.txt](INSTALL-PROMPT-TR.txt) into a new Codex desktop task. It contains the pinned GitHub URLs, SHA-256 hashes, destination rules, backup behavior, and post-install verification instructions; no plugin must be installed first.

The shorter prompts below require the `clippy-for-chatgpt` plugin to be installed first.

## English

```text
Use $install-clippy-pet to install the bundled Clippy pet into Codex and verify it. If a different Clippy pet would be overwritten, ask me first.
```

## Türkçe

```text
$install-clippy-pet becerisini kullanarak paketteki Clippy petini Codex'e kur ve doğrula. Farklı bir Clippy paketinin üzerine yazılacaksa önce benden onay iste.
```

## Verify only

```text
Use $install-clippy-pet to verify the installed Clippy pet without replacing or changing files.
```

## Uninstall

```text
Use $install-clippy-pet to uninstall only the bundled Clippy pet. Do not remove any other pet or Codex setting.
```
